# 감사의 말과 개발 과정 공개

## 선행 사례와 비교 자료

grid-masonry는 동일한 입력에 항상 같은 결과를 내는 배치, 동적 측정, 공간
질의, 대규모 목록 처리를 설계하면서 masonry와 가상화 생태계의 여러 접근
방식을 살펴보았습니다. 다른 프로젝트를 언급하는 것은 선행 사례로
연구하거나 비교했다는 뜻입니다. 별도로 명시하지 않는 한, 해당 프로젝트의
소스 코드가 grid-masonry에 포함되었다거나 grid-masonry가 그 프로젝트에서
갈라져 나왔다는 뜻은 아닙니다. 해당 프로젝트나 유지관리자가
grid-masonry를 보증한다는 뜻도 아닙니다.

## 검토한 통합 대안

Embla Carousel, Swiper, Keen Slider는 가로 레이아웃을 검토하면서 스크롤과
표시 영역 처리, 배치 계산의 책임을 어디까지 분리할지 비교하기 위한 참고
대상으로 살펴보았습니다. 이 프로젝트들은 grid-masonry의 실행 시 의존성이
아닙니다. 각 프로젝트의 유지관리자와 기여자에게 감사드리며, 이 언급이
해당 프로젝트의 보증이나 제휴 관계를 의미하지는 않습니다.

## 독립적인 구현

grid-masonry는 플랫폼에 의존하지 않는 배치 계산 Core와 별도의 React 및
Browser 어댑터를 중심으로 독립적으로 설계되었습니다. Core에는 실행 시
의존성이 없으며, 다른 프로젝트의 배치 코드나 캐러셀 구현을 함께 배포하지
않습니다.

## 개발 과정 공개

구현, 테스트, 문서 작성, 분석과 검토 과정에서 AI 기반 개발 도구를
활용했습니다. AI가 제안하거나 생성한 내용은 검토할 작업 재료로
다루었으며, 그 자체를 승인 기준으로 삼지 않았습니다.

공개 API, 구조와 책임 범위, 테스트 기준, 기능 동결, 출시 여부는 사람이
검토하고 결정했습니다. 각 결정은 저장소의 소스 코드와 실제 테스트 결과를
바탕으로 확인했습니다. 게시된 소프트웨어와 출시 결정에 대한 최종 책임은
프로젝트 유지관리자에게 있습니다.

## 제3자 소프트웨어와 고지

공개 패키지와 사이트를 검토한 결과, 복사한 제3자 소스 코드나 함께 배포하는
제3자 자료는 발견되지 않았으며 별도로 표시해야 할 저작권·라이선스 고지도
없었습니다. 개발 환경이나 호스트 애플리케이션에서 실제로 사용하는
의존성에는 각각의 라이선스가 적용됩니다.
